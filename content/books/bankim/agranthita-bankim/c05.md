<p class="pc"><strong>১</strong><br/>
প্রথম দশা দিনে, <span class="gap-50"></span>        বেরি বেরি রোওল<br/>
শেজে পাড়ি কাঁদে ভূমি লুটি।<br/>
দ্বিতীয় দশা দিনে,   <span class="gap-50"></span>      আঁখি মেলি হেরল,<br/>
শেজ ছাড়ি গা ভাঙ্গিল উঠি॥<br/>
<br/>
<strong>২</strong><br/>
তৃতীয় দশা দিনে,    <span class="gap-50"></span>     মৃদু মৃদু হাসিল,<br/>
বলে কোথা গেলে প্রাণনাথ।<br/>
চউঠ দশা দিনে,  <span class="gap-50"></span>       সিনান করি আওল,<br/>
হাঁড়ি পাড়ি খাওল পান্তা ভাত॥<br/>
<br/>
<strong>৩</strong><br/>
পঞ্চম দশা দিনে,     <span class="gap-50"></span>           বান্ধি চারু কবরী,<br/>
ঢাকাই শাড়িতে দিল ফের।<br/>
ষষ্ঠম দশা দিনে,    <span class="gap-50"></span>         পিঠা পুলি বানাওল,<br/>
কাঁদিতে ২ তার গিলিল তিন সের॥<br/>
<br/>
<strong>৪</strong><br/>
সপ্তম দশা দিনে,   <span class="gap-50"></span>         সজিনা খাড়া রাঁধিল<br/>
বলে প্রাণ বঁধূ কোথা গেলে।<br/>
যে খাঁড়া রেঁধেছি ভাই,  <span class="gap-50"></span>    তুমি বঁধূ কাছে নাই,<br/>
যদি পেট ফাঁপে একা খেলে॥<br/>
<br/>
<strong>৫</strong><br/>
অষ্টম দশা দিনে,   <span class="gap-50"></span>   বিরহ বিষাদিনী,<br/>
মন দুঃখে কিনিল ইলিশ।<br/>
তিতিয়া নয়ন জলে,  <span class="gap-50"></span>    ভাজায় ঝোল অম্বলে,<br/>
খায় ধনী খান বিশ ত্রিশ॥<br/>
<br/>
<strong>৬</strong><br/>
নবম দশার দিনে,  <span class="gap-50"></span>     পেট ফেঁপে ঢাক হলো,<br/>
আইল কানাই কবিরাজ।<br/>
সই বল কর্মভোগ,  <span class="gap-50"></span>    এ ঘোর বিরহ রোগ,<br/>
কবিরাজের নাহি ইথে কাজ॥<br/>
<br/>
<strong>৭</strong><br/>
দশম দশা দিনে,   <span class="gap-50"></span>     বিরহিণী মরে নরে,<br/>
আই ঢাই বিছানায় পড়ি।<br/>
কাতরে কহিছে সতী,  <span class="gap-50"></span>    কোথা পাব প্রাণপতি,<br/>
কোথা পাব পাচকের বড়ি॥<br/>
<br/>
<strong>৮</strong><br/>
বিরহীর দশ দশা,  <span class="gap-50"></span>    পন্ পন্ করে মশা,<br/>
মাছি উড়ে ছেলে কাঁদে কোলে।<br/>
চাকরাণীর চীৎকার,   <span class="gap-50"></span>     সইসাঙ্গতির টিট্‌কার,<br/>
খেদে কবি ছন্দোবন্ধ ভোলে॥</p>

<p class="right ugap"><span class="gap-50"></span>—‘বঙ্গদর্শন’, ফাল্গুন, ১২৭৯</p>
</div>
