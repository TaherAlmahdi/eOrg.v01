<div class="pc">
(তিন মিত্রের কথোপকথন)<br/><br/>
প্রথম মিত্র<br/>
কি বিষাদে মুখখানি, হাসি-ভরা নাই।<br/>
বেণা-বনে বোসে কেন, উঠ উঠ ভাই॥<br/>
<br/>
দ্বিতীয় মিত্র<br/>
দেখিয়া দেশের গতি, কেঁদে মরি মনে।<br/>
সে দুখে বসিয়া আছি, বিরস বদনে॥<br/>
<br/>
তৃতীয় মিত্র<br/>
সখা রে বচন ধর, <span class="gap-50"></span> মিছা দুখ পরিহর,<br/>
নিজ সুখে সুখী হও ভাই।<br/>
<br/>
দ্বিতীয় মিত্র<br/>
নিজ সুখ এ সংসারে,<span class="gap-50"></span>বন বন বল কারে,<br/>
আমি তো সে সুখ দেখি নাই॥<br/>
<br/>
তৃতীয় মিত্র<br/>
না জেনে কহিছ ভাই, <span class="gap-50"></span> সংসারে সে সুখ নাই,<br/>
জান না তো কার কাছে পাবে।<br/>
রাখ রে মানস পুরী, <span class="gap-50"></span> প্রমদার প্রেমে পূরি,<br/>
কত সুখে তোমারে মজাবে॥<br/>
পদে পদে প্রেম পথে, <span class="gap-50"></span> মজাইবে মনোরথে,<br/>
মহিলার মোহন বদনে।<br/>
মোহ মন্ত্রে রবে বাঁধা, <span class="gap-50"></span>মানিবে না কোন বাধা,<br/>
কত সুখে রবে মনে মনে॥<br/>
<br/>
প্রথম মিত্র<br/>
এ কথাটি ভাল বটে, রটে ধরাময়।<br/>
পরম পুলকপ্রদ, প্রমদা প্রণয়॥<br/>
বিশেষতঃ কত তাহে, ধর্ম্মের সঞ্চার।<br/>
বিবাহ বিশেষ তাই, বিধি বিধাতার॥<br/>
নর নারী উভয়েতে, হইয়া মিলিত।<br/>
আরাধনে করিবেক, পরমেশে প্রীত॥<br/>
<br/>
দ্বিতীয় মিত্র<br/>
ছিছি ছিছি কেন ছার, <span class="gap-50"></span> মুখাম্বুজে মহিলার,<br/>
মরিয়াছ মোহিত হইয়া।<br/>
জানি জানি কত জ্বালা,<span class="gap-50"></span> দেয় প্রণয়িনী বালা,<br/>
হারিয়াছি বারেক ঠেকিয়া॥<br/>
সবে তার এক দিন,<span class="gap-50"></span> হই আমি প্রেমাধীন,<br/>
নাকে কাণে খৎ দি হে তায়।<br/>
আদরে ভাঙ্গাতে মনে, <span class="gap-50"></span>হইয়াছি অপমান,<br/>
না ভাঙ্গিল আমার কথায়॥<br/>
<br/>
প্রথম মিত্র<br/>
সব তার সহিলাম, <span class="gap-50"></span> কত কথা কহিলাম,<br/>
মধুর মিনতি কত করি।<br/>
রামায়ণ আদি নিয়া,<span class="gap-50"></span>সব কথা কাটাইয়া,<br/>
তবু মানে রহিলা সুন্দরী॥<br/>
<br/>
সামান্য রতন নহে, রমণী রূপসী।<br/>
তার না ভাঙ্গিবে মান, বেণা-বনে বসি॥<br/>
তাই বলি উঠ ভাই, পরিহরি দুখ।<br/>
বল তুমি বল কারে, পৃথিবীর সুখ॥<br/>
<br/>
দ্বিতীয় মিত্র<br/>
অনিত্য সকল সুখ নিত্য কারে বলি।<br/>
সকল সংসার সুখ, স্বপনে কেবলি॥<br/>
পৃথিবীতে আছে সুখ, কেবলি স্বপনে।<br/>
স্বপ্ন বিনে আর সুখ, নাহি জানি মনে॥<br/>
স্বপনে স্বকরে পাই, সংসার মণ্ডল।<br/>
স্বপনে নারীর দেখি, লপন কমল॥<br/>
ভারত জনম ভূমি, সতীত্ব অঙ্গনা।<br/>
শশিমুখী সরস্বতী, আর কত জানা॥<br/>
<br/>
তৃতীয় মিত্র<br/>
সে সব স্বপন ভাই, শ্রবণে তোমার।<br/>
শ্রবণে প্রবেশ করে, শত সুধাধার॥<br/>
কবি দেখ ছেলে দেখ, দেখ গিয়া মেয়ে।<br/>
স্বপনে জিনেছ ভাই, সকলের চেয়ে॥<br/>
মধুর সরল ভাষে, মুগ্ধ কর মন।<br/>
করুণায় ভেসে যায়, নীরেতে নয়ন॥<br/>
রসিক তুমি, জানি ইহাতেই।<br/>
স্বপ্ন দরশনে দেখ, সতীত্ব নিজেই॥<br/>
<br/>
প্রথম মিত্র<br/>
এখন হে জানিলাম, স্বপ্নে যত সুখ।<br/>
এসো মিত্র স্বপ্নে মোরা, ঘুচাইব দুখ॥<br/>
<br/>
তৃতীয় মিত্র<br/>
স্বপনে আমার ভাই, মন নাই ভজে।<br/>
আসল পাইলে বল, নকলে কে মজে॥<br/>
বিশেষ একেতে আমি, ডরি হে কতক।<br/>
একেবারে তাড়াবো না দেশের র* ক॥<br/>
<br/>
প্রথম মিত্র<br/>
ওই দোষে চিরকাল, মরিলি রে তুই।<br/>
ভাল কথা তোর মুখে, শুনি নি কভুই॥<br/>
<br/>
তৃতীয় মিত্র<br/>
তুমিই তো ওই রসে, মজিয়াছ ভাই।<br/>
সে কথা শুনেছি ভাল, কামিনীর ঠাঁই॥<br/>
চতুর জামাই হও, শ্বশুরের ঘরে।<br/>
ফুল খেলা কত জানো, বাগান ভিতরে॥<br/>
কিন্তু আহা মরি মরি, কামিনীর রূপ।<br/>
কি মোহন মন্ত্র দিয়ে, বর্ণেছ স্বরূপ॥<br/>
মধুর মোহন ভাষে, মোহিনী বর্ণন।<br/>
বুঝি হে কখনো আর, ভুলিবে না মন॥<br/>
<br/>
এই সময়ে শ্যামাচন্দ্র বিশ্বদাস ও গুপ্ত নাম কয়েক<br/>
জন পুলিস সংক্রান্ত শস্ত্রধারী আসিয়া কহিল যে,<br/>
<br/>
চোর চোর ধর চোর, এই জন চোর।<br/>
পর ধন কর চুরি, এত সাধ্য তোর॥<br/>
<br/>
তৃতীয় মিত্র<br/>
বাহারে! এ যে হে বড়, বাহারে চাতুরী।<br/>
বল দেখি কার কিবা, করিয়াছ চুরি॥<br/>
<br/>
গুপ্ত<br/>
কার কি করেছো চুরি, এ তো নাহি জানি।<br/>
<br/>
বিশ্বদাস<br/>
বলেছে তোমারে চোর, শুধু অনুমানি॥<br/>
<br/>
তৃতীয় মিত্র<br/>
ভাল ভাল এত বুদ্ধি, প্রশংসার বটে।<br/>
না জানিয়া চোর বলা, সুবুদ্ধিতে ঘটে॥<br/>
<br/>
শ্যামাচন্দ্র<br/>
না জানিয়া তোরে কভু, চোর বলি নাই।<br/>
তাহার কারণ তবে, শুন মোর ঠাঁই॥<br/>
সে কালের কালী বাবু, বড় ধনবান্<br/>
পোরেছিল ছ পাড়ের, ধুতি একখান॥<br/>
তুমিও তো ছ পাড়ের, ধুতি পরিয়াছ।<br/>
তাই বলি তার ধুতি, চুরি করিয়াছ॥<br/>
<br/>
তৃতীয় মিত্র<br/>
বটে বটে দিব্য আছে, এই পৃথিবীতে।<br/>
দু খানি ছপেড়ে ধুতি, নারিবে জন্মিতে॥<br/>
<br/>
শ্যামাচন্দ্র<br/>
চোপ্ চোপ্ চোপ্ রহ, মৎ কর সোর।<br/>
পুলিসের ম্যাজিষ্ট্রেটি, পদ আছে মোর॥<br/>
আমি বলিতেছি তুই, চুরি কোরেছিস্।<br/>
আমার কথায় হয়, ডিক্রী বা ডিস্মিস্॥<br/>
<br/>
তৃতীয় মিত্র<br/>
যো হুকুম খোদা-বন্দ, হইল ইয়াদ্।<br/>
বল দেখি কত দিন, খাটিব মিয়াদ॥<br/>
<br/>
গুপ্ত<br/>
মানিলাম নাহি তুমি, করিয়াছ চুরি।<br/>
তবু দোষ দেখাইতে, পারি ভূরি ভূরি॥<br/>
<br/>
প্রথম মিত্র<br/>
কেবলি দেখায়ে দোষ, কি লাভ তোমার।<br/>
<br/>গুপ্ত<br/>
দোষ দেখানো হে বাপু, ব্যবসা আমার॥<br/>
তোমারো সহস্র দোষ, দেখাইতে পারি।<br/>
বিশ্বদাস তাহে মোর, আছে সহকারী॥<br/>
<br/>
প্রথম মিত্র<br/>
ভাল ভাল সাধু সাধু, কি নাম তোমার।<br/>
অসার সংসারে শুধু, তুমি প্রশংসার॥<br/>
<br/>
গুপ্ত<br/>
গুপ্ত রাখিলাম বাপু, নামটি আমার।<br/>
গু আছে প্রথমে তার মধ্যেতে পকার॥<br/>
<br/>
তিন জন পুলিস প্রহরী<br/>
কথার গতিক বড়, উত্তম না ঘটে॥<br/>
স্বস্থানে প্রস্থান করা, যুক্তি মত বটে॥</div>

<div class="pc">
তৃতীয় মিত্র<br/>
<br/>
সময় হোতেছে নাশ, <span class="gap-50"></span> যাই নিজ নিজ বাস,<br/>
কি করিব ভেবে দেখি মনে।<br/>
তুমি যাও এই বেলা,<span class="gap-50"></span> কর গিয়া ফুল খেলা,<br/>
যামিনীতে কামিনীর সনে॥<br/>
তুমি ত্যজিবে না বনে,<span class="gap-50"></span>ভাবো গিয়ে নিজ মনে,<br/>
আজিকে দেখিবে কি স্বপন।<br/>
আমি বাড়ী গিয়ে ভাই,<span class="gap-50"></span> মনসুখে নিদ্রা যাই,<br/>
স্বপন কি, না জানি কখন॥<br/>
তবে গো বিদায় হই,<span class="gap-50"></span>প্রণয়েতে যেন রই,<br/>
এই আশা করে মোর মন।<br/>
যদি কোন কথা মোর,<span class="gap-50"></span>হয়ে থাকে অতি জোর,<br/>
then beg you pardon.<br/>
</div></div>
