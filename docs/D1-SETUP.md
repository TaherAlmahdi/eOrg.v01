# পাঠকপ্রিয় বই — Cloudflare D1 চালু করার ধাপ (আপনি করবেন)

কোড তৈরি আছে। D1 না থাকলে সাইট ঠিকই চলে, শুধু "পাঠকপ্রিয় বই" সেকশন লুকানো থাকে।

## ১. D1 ডাটাবেজ বানান
```
npx wrangler d1 create eorg-db
```
আউটপুটে `database_id` পাবেন।

## ২. `wrangler.jsonc`-এ binding যোগ করুন
`r2_buckets`-এর পাশে (binding নাম অবশ্যই `DB`):
```jsonc
"d1_databases": [
  {
    "binding": "DB",
    "database_name": "eorg-db",
    "database_id": "<ধাপ ১-এর database_id>"
  }
],
```
(এই ফাইলে চাবি-সংক্রান্ত অংশ আপনি পরে সরাবেন বলেছেন, আমি ছুঁইনি।)

## ৩. টেবিল তৈরি
```
npx wrangler d1 execute eorg-db --remote --file=migrations/0001_book_views.sql
```

## ৪. ডিপ্লয় ও যাচাই
- ডিপ্লয়ের পর যেকোনো বই খুললে ১টি ভিউ গোনা হবে (একই ব্রাউজার থেকে একই বই দিনে একবার)।
- ড্যাশবোর্ডে বা `npx wrangler d1 execute eorg-db --remote --command "SELECT * FROM book_views ORDER BY views DESC LIMIT 10"` দিয়ে দেখুন।
- লাইব্রেরি হোমে ভিউ জমলে "নতুন বই"-এর নিচে "পাঠকপ্রিয় বই" আসবে। তালিকা প্রতি ১০ মিনিটে হালনাগাদ হয়।

## কীভাবে খরচ কম রাখা হয়েছে
- ব্রাউজার থেকে দিনে একবারের বেশি লেখা যায় না।
- বট/ক্রলার গোনা হয় না; শুধু বিদ্যমান বইয়ের স্লাগ গোনা হয়।
- হোমপেজ D1 পড়ে ১০ মিনিটে সর্বোচ্চ একবার (মেমরি ক্যাশ)।
- এক বইয়ের জন্য এক সারি।

## নোট
- এখন গণনা সর্বকালের ভিউ। চাইলে পরে "এই মাসের জনপ্রিয়" যোগ করা যায় (দৈনিক টেবিল লাগবে)।
- স্থানীয় `next dev`-এ D1 নেই, তাই সেকশনটি সেখানে দেখা যাবে না।
